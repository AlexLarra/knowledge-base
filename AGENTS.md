# AGENTS.md

## Repository Goal

This repository is a collection of technical guides, notes and tutorials aimed at developers. Each topic directory contains one or more `.md` files explaining useful concepts or procedures for day-to-day work.

The content is intended to be published online using **GitHub Pages** and **MkDocs**, so that anyone can access the guides comfortably from a browser.

## How to Contribute

- Each new topic should go in its own directory (e.g. `tmux/`, `git/`, `docker/`).
- One or more Markdown files can be created inside each directory.
- The root `README.md` acts as a general index and must list the available topics.
- When adding a new topic, update `README.md` to include a link to it.

## Publishing

**MkDocs** with the Material theme will be used to generate the static site, and **GitHub Pages** will host it. The MkDocs configuration will be defined in an `mkdocs.yml` file in the project root.
